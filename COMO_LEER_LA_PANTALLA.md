# Cómo leer la app 1.0

- **Proyecto:** selecciona una carpeta de trabajo independiente.
- **Objetivo verificable:** registra features y tolerancias esperadas.
- **Design:** piezas geométricas y parámetros con unidad/tipo.
- **Visualización:** V en meV; en 2D ofrece superficie y vista superior.
- **Verificación:** separa validez del Design, solver, COMSOL y coincidencia del objetivo.
- **Solver:** muestra energías, umbral de escape, estados ligados, malla, dominio y fuga.
- **Historial:** cada guardado conserva una revisión y cada `verify` una carpeta inmutable.
- **Exportar:** `.mph` es estricto; una receta alternativa requiere solicitud explícita.

Consulta [README.md](README.md) para instalación y flujo completo.
